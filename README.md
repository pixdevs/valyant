# Valyant IT Groups Website

This repository contains the source for the Valyant IT Groups website.

It is a static website intended for deployment on GitHub Pages.

## Local preview

Open `index.html` in a browser, or serve the folder with any static server:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Deployment
Push to the `main` branch and publish the site through GitHub Pages in the repository settings.
